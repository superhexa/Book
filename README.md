# منصة كرة القدم الأردنية | Jordan Football Platform

منصة رياضية متكاملة لكرة القدم في الأردن — حجز الملاعب، الدوريات، البطولات، الفرق، واللاعبين.

A complete, production-ready football sports platform for Jordan.

## البنية | Structure

- `backend/` — FastAPI + MongoDB API (Arabic-first, JOD, Asia/Amman)
- `frontend/` — Expo (React Native + Web), Arabic RTL, PWA-ready
- `docs/` — Setup, API, architecture documentation
